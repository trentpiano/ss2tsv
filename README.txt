ss2tsv byとれんと

動作環境
Windows10 / 11
画面サイズフルHD以上推奨

導入方法
ダウンロードしたzipファイルを解凍し、ドキュメントなど任意の場所に置いてください。
windowsのセキュリティにソフトの実行が止められる場合があります。そのときは以下の手順を実行してください。
1.win+Sで「windowsセキュリティ」と検索しアプリを開く
2.「保護の履歴」タブからブロックされた操作を見つける
3.操作をデバイスで許可してください


使い方
1:exeファイルを実行する。
2:出てきたウィンドウに、対抗戦のリザルト画面のスクリーンショットをドラッグアンドドロップする。
3:対戦相手の先生の名前を入力する（初回のみ）。
4:編成されている生徒の名前を入力する（初回のみ）。
5:全ての処理が終わるとクリップボードにTSVがコピーされます。Excelやスプレッドシートにそのまま貼り付けできます。
