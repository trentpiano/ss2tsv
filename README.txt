ss2tsv byとれんと

動作環境
Windows10 / 11
画面サイズフルHD以上推奨

導入方法
ダウンロードしたzipファイルを解凍し、ドキュメントなど任意の場所に置いてください。
windowsのセキュリティにソフトの実行が止められる場合があります。そのときは以下の手順を実行してください。
1.win+Sで「windowsセキュリティ」と検索しアプリを開く
2.「保護の履歴」タブからブロックされた操作を見つける
3.操作をデバイスで許可してください

使い方
1:exeファイルを実行する。
2:出てきたウィンドウに、対抗戦のリザルト画面のスクリーンショットをドラッグアンドドロップする。
3:対戦相手の先生の名前を入力する（初回のみ）。
4:編成されている生徒の名前を入力する（初回のみ）。
5:全ての処理が終わるとクリップボードにTSVがコピーされます。Excelやスプレッドシートにそのまま貼り付けできます。

設定ファイル（config.json）
このファイルを編集することで、育成状況の入力機能や入力順序などを変更できます。
| 項目 | 設定値 | 説明 |
| `growth_input_enabled` | `true` / `false` | 育成状況の入力機能を有効・無効にします。`false` にすると、育成状況の入力を行わず、通常の解析結果のみを出力します。 |
| `growth_input_order` | `oldest_first` / `newest_first` | 育成状況を入力する順序を指定します。`oldest_first` は古い画像から、`newest_first` は新しい画像から入力します。 |
| `growth_input_mode` | `dialog` / `clipboard` | 育成状況の入力方法を指定します。`dialog` は専用の入力画面を使用し、`clipboard` はクリップボードにコピーされたテキストを読み込みます。 |
育成状況入力機能について、相手防衛の見せがエイミ固有4、ミチル（ドレス）固有2、ヤクモ固有1のとき、「421」と入力します。固有武器を持っていない時、例えばヤクモが星3の場合は「42!3」と入力してください。
改行することで入力をスキップすることができます。私はスプレッドシートで匿名の相手だけメモして、ほかは空白にしてクリップボードにコピーして使っています。
